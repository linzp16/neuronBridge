# NeuronBridge v0.1.0a3 (prerelease)

## Changes

- Add ROKAE_Arm native state feedback (product and single-variable encoding)
  and signed positive/negative CF teaching spikes for six-axis cerebellar control.
- Expose encoding ranges, feedback timing, repeat counts, normalization and
  random seed parameters through the Python ROKAE factory.
- Add six-axis cerebellar training, continuous-IK XY-circle targets, endpoint
  plotting, parameter comparisons and frozen-weight replay examples.
- Training examples default to neural-only control. PD assistance requires
  an explicit opt-in; this does not change the general native model's default.
- Add ROKAE PD-off torque-isolation, feedback and circle regression tests.
- Make Windows wheel builds explicitly refresh the CMake version from VERSION
  instead of retaining an obsolete version in an existing build cache.

## Binary asset

`neuronbridge-0.1.0a3-cp312-cp312-win_amd64.whl`

- Windows x86-64, CPython 3.12.
- Includes CPU, dense and CUDA backend support, Pinocchio, ZeroMQ and private
  MSVC/OpenMP runtime dependencies. CUDA execution requires a compatible driver.
- SHA-256: `18bc1efcfc51eded553cac171ece7fbb603507ae1138099953baba547f6b6c7e`
- No new Linux binary is included in this release.

After downloading the wheel:

```powershell
python -m pip install --upgrade .\neuronbridge-0.1.0a3-cp312-cp312-win_amd64.whl
python -c "import neuronbridge as nb; print(nb.__version__, nb.__file__)"
```

## Verification (2026-10-12)

- Version consistency: PASS (VERSION, CMake, pyproject, Python package).
- Wheel contents and private runtime inspection: PASS.
- Fresh isolated installed-wheel CUDA/runtime/custom learning-rule smoke: PASS.
- Installed-wheel Python/API and release tests: **118 passed, 5 skipped**;
  two expected noninteractive Matplotlib warnings.
- ROKAE native and circle tests are included, with the xMate URDF supplied.
- The five optional data-dependent example cases remain skipped.
- This is a focused release validation, not a repeat of every historical
  external-server, robot-scene, performance or Linux acceptance experiment.

The pure-neural example achieved 25.40 mm endpoint RMSE after 100 epochs in the
tested simulated circle task, with 10.17 mm first/last sample separation during
frozen replay. This is not precise trajectory convergence or physical-robot
validation. An external xMate URDF is required and is not included.

visual-network experiment edits are excluded from this source update.
